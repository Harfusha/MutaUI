# CLI and capabilities / CLI a schopnosti

## English

MutaUI discovers and uses the locally installed Mutagen CLI. Onboarding checks its version and sync/forward help; option support is determined from the installed binary and endpoint/platform context. Do not infer support from a remembered release. Unknown native values stay visible and unsupported actions fail closed with a reason. The official command reference is the [Mutagen documentation](https://mutagen.io/documentation/introduction/getting-started).

See the project [capability matrix](../capability-matrix.md) for application feature gates and the generated [configuration fields](configuration-fields.md) for mapped settings.

## Česky

MutaUI vyhledává a používá místní instalaci Mutagen CLI. Průvodce ověří verzi a nápovědu sync/forward; podporu voleb zjišťuje z nainstalovaného binárního souboru, endpointu a platformy. Podporu neodvozujte z paměti o jiné verzi. Neznámé nativní hodnoty zůstávají viditelné a nepodporované akce se zablokují s důvodem. Oficiální reference příkazů je v [dokumentaci Mutagenu](https://mutagen.io/documentation/introduction/getting-started).

Viz [matici schopností](../capability-matrix.md) a generovaná [pole konfigurace](configuration-fields.md).
