# Compatibility matrix / Matice kompatibility

## English

Compatibility is discovered from the installed Mutagen CLI and endpoint capabilities. Packaging existence does not prove that a platform is supported. Current CI builds Windows x64, macOS Apple Silicon/Intel, and Ubuntu x86-64 packages; native manual GUI acceptance and Linux compatibility outside the Ubuntu image remain open. Compatibility across Mutagen releases and endpoint types is not yet fully established.

See the maintained [capability matrix](../capability-matrix.md) and [acceptance traceability](../acceptance-traceability.md) before relying on platform-specific features.

## Česky

Kompatibilita se zjišťuje podle nainstalovaného Mutagen CLI a schopností endpointu. Existence balíčku nedokazuje podporu platformy. CI nyní vytváří Windows x64, macOS Apple Silicon/Intel a Ubuntu x86-64 balíčky; ruční GUI akceptace na nativních systémech a Linux mimo Ubuntu obraz zůstávají otevřené. Kompatibilita napříč verzemi Mutagenu a endpointy zatím není úplně stanovena.

Před použitím funkcí specifických pro platformu ověřte [matici schopností](../capability-matrix.md) a [přehled akceptace](../acceptance-traceability.md).
