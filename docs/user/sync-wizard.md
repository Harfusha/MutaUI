# Sync wizard / Průvodce synchronizací

## English

The **New Sync** wizard previews endpoints, sync mode, direction, native arguments, and known effective configuration before starting. Basic mode offers a smaller set of safer choices. Advanced exposes additional native modes, including resolved and replica, with explicit risk confirmation. Ignore presets are ordered and previewed; `.gitignore`/`.dockerignore` conversion is staged and does not edit the source file. The preview must be reviewed because Mutagen can propagate deletions.

Begin with [First sync](../getting-started/first-sync.md). See the [installation overview](../installation.md) and [capability limits](../capability-matrix.md).

## Česky

Průvodce **New Sync** před spuštěním zobrazuje endpointy, režim a směr synchronizace, nativní argumenty a známou výslednou konfiguraci. Základní režim nabízí menší sadu bezpečnějších voleb. Pokročilý zpřístupňuje další nativní režimy včetně resolved a replica s výslovným potvrzením rizika. Ignore presety jsou seřazené a zobrazují náhled; převod `.gitignore`/`.dockerignore` je pouze návrh a zdrojový soubor neupravuje. Náhled vždy zkontrolujte, protože Mutagen může přenášet i mazání.

Začněte [první synchronizací](../getting-started/first-sync.md). Viz [instalační přehled](../installation.md) a omezení v [matici schopností](../capability-matrix.md).
