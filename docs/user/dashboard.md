# Dashboard / Přehled

## English

The dashboard reads the local Mutagen session inventory. Server groups are derived from endpoint strings; opening the page does not perform DNS lookups or create SSH connections. Double-click a sync session or select it and press Enter to open its details. This clears the Sync page filters so the selected session is visible. Unknown telemetry stays unknown rather than being shown as zero. The application can follow an existing local Mutagen log file, but does not stream the remote agent's complete internal debug log.

See [screenshots](../screenshots.md), [session health](../session-health.md), and [settings reference](../settings-reference.md).

## Česky

Přehled čte seznam relací z místního Mutagenu. Skupiny serverů se odvozují z řetězců endpointů; otevření stránky neprovádí DNS dotazy ani SSH spojení. Podrobnosti synchronizační relace otevřete dvojklikem nebo klávesou Enter po jejím výběru. Aplikace přitom zruší filtry na stránce Synchronizace, aby byla vybraná relace vidět. Neznámé metriky zůstávají neznámé, nezobrazují se jako nula. Aplikace může sledovat existující místní log Mutagenu, ale nezobrazuje úplný interní ladicí log vzdáleného agenta.

Viz [snímky obrazovky](../screenshots.md), [zdraví relace](../session-health.md) a [přehled nastavení](../settings-reference.md).
