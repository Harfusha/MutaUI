# Conflicts and recovery / Konflikty a obnova

## English

The conflict inspector displays locally available Mutagen conflict metadata. Remote inspection is separate and runs only after an explicit request. Compare copies before choosing a resolution. A resolution preview is tied to the observed file state; if the file changes after preview, the operation must stop and preserve the backup. Do not use reset, replace, or terminate as a shortcut to recover data.

Follow the [conflict inspector](../conflict-inspector.md), [copy comparison](../conflict-diff.md), [recommendations](../conflict-recommendations.md), and [manual resolution](../manual-conflict-resolution.md) guides.

## Česky

Inspektor konfliktů zobrazuje lokálně dostupná metadata konfliktů Mutagenu. Vzdálená inspekce je oddělená a spouští se jen na výslovnou žádost. Před volbou řešení porovnejte kopie. Náhled řešení je svázán s pozorovaným stavem souboru; změní-li se soubor po náhledu, akce se musí zastavit a zachovat zálohu. Reset, nahrazení ani ukončení relace nepoužívejte jako rychlou obnovu dat.

Postupují [inspektor konfliktů](../conflict-inspector.md), [porovnání kopií](../conflict-diff.md), [doporučení](../conflict-recommendations.md) a [ruční řešení](../manual-conflict-resolution.md).
