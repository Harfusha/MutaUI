# Connections / Připojení

## English

MutaUI delegates session transport to Mutagen. Use the New Sync or New Forward wizard to choose local paths, SSH endpoints, and supported forwarding endpoints. Connection Profiles store reusable endpoint pairs and defaults in a separate local file; selecting a profile applies defaults only to a new session. It does not alter a running session.

Before creating a session, inspect the endpoint strings and command preview. For SSH aliases and strict host-key checks, see [SSH profiles](ssh.md). For endpoint capabilities, see the [capability matrix](../capability-matrix.md).

## Česky

Přenos relací zajišťuje Mutagen. V průvodci New Sync nebo New Forward vyberte místní cesty, SSH endpointy a podporované endpointy přeposílání. Connection Profiles ukládají opakovatelné dvojice endpointů a výchozí hodnoty do samostatného místního souboru; profil nastavuje výchozí hodnoty pouze pro novou relaci a nemění běžící relaci.

Před vytvořením zkontrolujte endpointy a náhled příkazu. SSH aliasy a striktní kontrolu host klíče popisují [SSH profily](ssh.md). Schopnosti endpointů jsou v [matici schopností](../capability-matrix.md).
