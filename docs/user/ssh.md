# SSH / SSH

## English

MutaUI uses the local OpenSSH client and Mutagen's SSH transport. It does not add host keys, alter key files, or disable strict host-key checking. Confirm host fingerprints independently before connecting. Remote inspection is an explicit separate action and remains constrained to approved paths.

See [SSH profiles](../ssh-profiles.md), [remote inspection](../remote-inspection.md), and the official [Mutagen SSH transport guide](https://mutagen.io/documentation/transports/ssh).

## Česky

MutaUI používá místní klient OpenSSH a SSH transport Mutagenu. Nepřidává host klíče, nemění soubory klíčů a nevypíná striktní kontrolu host klíče. Fingerprint ověřte nezávisle před připojením. Vzdálená inspekce je samostatná výslovná akce a zůstává omezená na schválené cesty.

Viz [SSH profily](../ssh-profiles.md), [vzdálená inspekce](../remote-inspection.md) a oficiální [dokumentaci SSH transportu Mutagenu](https://mutagen.io/documentation/transports/ssh).
