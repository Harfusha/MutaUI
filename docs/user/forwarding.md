# Forwarding / Přeposílání

## English

Use **New Forward** to review source and destination endpoints and the exact native CLI arguments before creating a forwarding session. TCP ports are range-checked; public bind addresses require explicit confirmation. Existing Unix socket values are read-only in session settings. Local socket overwrite, owner, group, and permissions are stored as MutaUI proposals and must be checked against the installed Mutagen version and endpoint platform before replacement.

Forwarding operations target the selected session ID. See [settings reference](../settings-reference.md) and [replacement preview](../reconfiguration-preview.md).

## Česky

V **New Forward** zkontrolujte zdrojový a cílový endpoint i přesné argumenty nativního CLI před vytvořením relace. TCP porty se validují; veřejná adresa bind vyžaduje výslovné potvrzení. Existující hodnoty Unix socketu jsou v nastavení relace pouze pro čtení. Návrhy na přepsání místního socketu, vlastníka, skupiny a oprávnění se ukládají v MutaUI a před nahrazením se musí ověřit podle instalované verze Mutagenu a platformy endpointu.

Akce přeposílání míří na ID vybrané relace. Viz [přehled nastavení](../settings-reference.md) a [náhled nahrazení](../reconfiguration-preview.md).
