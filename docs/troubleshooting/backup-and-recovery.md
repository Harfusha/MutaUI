# Backup and recovery / Záloha a obnova

## English

Before changing or replacing a session, keep a known-good copy of important data and inspect the exact operation preview. For conflict resolution, compare the available copies and preserve the resolver's backup. If a file changed after preview, stop and review again. Do not use reset or terminate to clear uncertainty.

Settings migration creates an exact pre-migration byte backup and validates the new file; rollback is limited to a valid sibling backup and creates a pre-rollback copy. Portable imports preview choices before writing and create per-file backups. See [manual conflict resolution](../manual-conflict-resolution.md), [controlled replacement](../controlled-replacement.md), [settings schema](../reference/app-settings-schema.md), and [portable profile schema](../reference/profile-export-schema.md).

## Česky

Před změnou nebo nahrazením relace uchovejte známou dobrou kopii důležitých dat a zkontrolujte přesný náhled operace. U řešení konfliktu porovnejte dostupné kopie a zachovejte zálohu resolveru. Změní-li se soubor po náhledu, zastavte se a proveďte novou kontrolu. Reset ani ukončení nepoužívejte k odstranění nejistoty.

Migrace nastavení vytvoří přesnou bajtovou zálohu před migrací a ověří nový soubor; rollback je omezen na platnou sousední zálohu a vytvoří kopii před obnovou. Přenosný import nejprve zobrazí volby a vytváří zálohy měněných souborů. Viz [ruční řešení konfliktu](../manual-conflict-resolution.md), [řízené nahrazení](../controlled-replacement.md), [schéma nastavení](../reference/app-settings-schema.md) a [schéma přenosu profilů](../reference/profile-export-schema.md).
