# Basic and Advanced / Základní a pokročilý režim

## English

Basic and Advanced are views over the same Mutagen backend and stored session state. Switching views does not rewrite Mutagen configuration. Basic presents a smaller set of pages and safer sync choices; Advanced exposes native options, resolved/replica modes, and higher-risk operations with explicit confirmations. Some settings depend on installed Mutagen version, endpoint type, and platform; MutaUI shows unsupported or unknown values instead of inventing behavior.

Review the exact command and impact preview before applying a change. Replica mode and other high-risk actions require stronger confirmation. Creation profiles apply to new sessions; changing a profile does not modify an existing session. See the [settings reference](../settings-reference.md), [capability matrix](../capability-matrix.md), and [conflict recovery](../manual-conflict-resolution.md).

## Česky

Základní a pokročilý režim jsou pohledy nad stejným backendem Mutagenu a stejným uloženým stavem relací. Přepnutí nepřepisuje konfiguraci Mutagenu. Základní režim nabízí méně stránek a bezpečnější volby synchronizace; pokročilý zpřístupňuje nativní volby, režimy resolved/replica a rizikovější operace s výslovným potvrzením. Některá nastavení závisí na nainstalované verzi Mutagenu, endpointu a platformě; MutaUI neznámé nebo nepodporované hodnoty zobrazí, místo aby odhadovalo jejich chování.

Před změnou zkontrolujte přesný příkaz a náhled dopadu. Režim replica a další rizikové operace vyžadují přísnější potvrzení. Profily pro vytvoření platí pro nové relace; jejich změna nepřepisuje existující relaci. Viz [přehled nastavení](../settings-reference.md), [matice schopností](../capability-matrix.md) a [obnova po konfliktu](../manual-conflict-resolution.md).
