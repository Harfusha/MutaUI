# Recovery policies / Zásady obnovy

## English

Recovery starts with preserving the current evidence and a known-good copy. Do not reset or replace a session simply to clear an error. MutaUI's recommendations are advisory; a user must review conflict copies and the operation preview. A resolver must stop if the selected file changes after preview and preserve its backup. Incomplete or ambiguous CLI outcomes remain visible for manual recovery.

Use [Conflict Inspector](../conflict-inspector.md), [manual conflict resolution](../manual-conflict-resolution.md), [controlled replacement](../controlled-replacement.md), and [Troubleshooting](../troubleshooting.md).

## Česky

Obnova začíná zachováním důkazů o stavu a známé dobré kopie. Relaci neresetujte ani nenahrazujte jen kvůli odstranění chyby. Doporučení MutaUI jsou orientační; uživatel musí zkontrolovat kopie konfliktu a náhled operace. Změní-li se vybraný soubor po náhledu, resolver se zastaví a zachová zálohu. Neúplný nebo nejednoznačný výsledek CLI zůstává viditelný pro ruční obnovu.

Použijte [inspektor konfliktů](../conflict-inspector.md), [ruční řešení konfliktu](../manual-conflict-resolution.md), [řízené nahrazení](../controlled-replacement.md) a [řešení potíží](../troubleshooting.md).
