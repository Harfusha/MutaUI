# Forward configuration / Konfigurace forward

## English

Forward session settings are owned by Mutagen. MutaUI shows existing native socket values read-only and stores proposed local socket overwrite, owner, group, and permission values separately. The New Forward wizard previews exact arguments. TCP ports are validated and public bind addresses require explicit confirmation. Unix socket behavior is capability-gated against the installed CLI and the endpoint's platform; remote SSH/Docker paths are not probed as local paths.

Review [the forwarding guide](../user/forwarding.md), [settings reference](../settings-reference.md), and [capability matrix](../capability-matrix.md) before replacing a session.

## Česky

Nastavení forward relace vlastní Mutagen. MutaUI ukazuje existující nativní hodnoty socketu pouze pro čtení a návrhy na přepsání socketu, vlastníka, skupiny a oprávnění ukládá samostatně. Průvodce New Forward zobrazuje přesné argumenty. TCP porty se validují a veřejný bind vyžaduje výslovné potvrzení. Chování Unix socketu se povoluje podle nainstalovaného CLI a platformy endpointu; vzdálené SSH/Docker cesty se nezkoumají jako místní.

Před nahrazením relace si přečtěte [průvodce přeposíláním](../user/forwarding.md), [přehled nastavení](../settings-reference.md) a [matici schopností](../capability-matrix.md).
