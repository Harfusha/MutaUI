# Session reconfiguration / Změna konfigurace relace

## English

Opening an existing session shows native values as read-only. Proposed values remain separate until the user asks for a replacement preview. Replacement validates every proposed field and option against the installed CLI and current endpoint capabilities; unknown fields, unsupported flags, or stale preflight state block execution. Review the affected exact session ID, command, backup choice, and recovery plan before confirming.

See [reconfiguration preview](../reconfiguration-preview.md), [controlled replacement](../controlled-replacement.md), and [settings reference](../settings-reference.md).

## Česky

Otevřená existující relace zobrazuje nativní hodnoty pouze pro čtení. Návrhy zůstávají oddělené až do výslovného požadavku na náhled nahrazení. Před spuštěním se každé pole i volba ověří proti nainstalovanému CLI a schopnostem endpointu; neznámá pole, nepodporované volby nebo zastaralý předběžný stav akci zablokují. Před potvrzením zkontrolujte přesné ID relace, příkaz, zálohu a plán obnovy.

Viz [náhled změny](../reconfiguration-preview.md), [řízené nahrazení](../controlled-replacement.md) a [přehled nastavení](../settings-reference.md).
