# Code of Conduct

We want participation in this project to be respectful, safe, and useful to people with different backgrounds and levels of experience.

## Expected behavior

- Be considerate and direct; critique ideas and code without attacking people.
- Welcome good-faith questions, corrections, and constructive disagreement.
- Respect privacy. Do not publish credentials, private keys, personal data, or private diagnostic logs.
- Do not harass, threaten, discriminate against, or deliberately disrupt other participants.

## Applying these rules

Project maintainers may edit or remove contributions that violate these rules and may restrict participation when needed to protect the community. To report a concern, contact the repository maintainers privately through an available repository contact channel. Do not include sensitive evidence in a public issue.
